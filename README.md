# ELITE

ELITE is an original Roblox arcade FPS prototype with a colorful paintball-inspired presentation and fast military-FPS mechanics.

## Current build
- First-person camera
- Team Deathmatch foundation
- Two teams: ELITE RED / ELITE BLUE
- Server-side raycast validation
- Assault rifle
- 30-round magazine + reserve ammo
- Reloading
- ADS
- Sprint
- Crouch
- Hitmarkers
- Headshot multiplier
- Elimination scoring
- Death tracking
- Arena generated at runtime
- Respawn points

## Studio
The repository includes `ELITE.rbxlx`, a Roblox place file. Open it with Roblox Studio.

Controls:
- Mouse 1: Fire
- Mouse 2: ADS
- R: Reload
- Left Shift: Sprint
- C: Crouch

This project uses original code and generated geometry rather than copying another game's proprietary assets/code.
